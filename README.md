# Pi-Pin - Kitboga Codejam 26 Entry

git.io demo: https://gm-doc.github.io/pi-pin/ 

This simple ad overlay is inspired by a software gore phone number selector meme I saw a while ago.
You get the 4 digit pin number to skip the ad and then you have to input it by scrolling the digits of π.
To make it possible to complete in ~2 minutes the pin isn't really random, it's selected from positions 200-800 of π by default.
